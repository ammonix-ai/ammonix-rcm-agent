# Contributing

Thanks for your interest in the Ammonix RCM Agent.

**Issues are welcome.** Bug reports, reproducibility problems, and questions about the
software are genuinely useful — please open an issue.

**Pull requests are by invitation.** Because this project is dual-licensed (research
license publicly, commercial licenses separately), accepting outside code requires
contributor agreements we currently keep deliberately simple by not taking unsolicited
PRs. If you've built something on this software you think belongs upstream, open an issue
describing it and we'll take it from there.

**Research collaborations:** if you're using this software in published research, we'd
like to hear about it — contact@ammonix.ai.
